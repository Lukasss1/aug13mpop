# Opening Content Setup

Milk Pop can be prepared before every business detail is final. Blank or unpublished information is handled deliberately rather than filled with fake content.

## Admin editing map

| Information | Where to edit | Safe opening behaviour |
|---|---|---|
| Homepage, About, footer wording and page images | Admin → Website | Editable at any time |
| Products, prices, images and availability | Admin → Menu | Empty menu shows “being prepared” |
| Store address, hours and contact details | Admin → Operations → Store Locations | Incomplete stores are not published or indexed |
| Public phone, email, address and company facts | Admin → Advanced → Company Settings → Launch Facts | Blank rows and the contact footer column are omitted |
| Announcement ribbon | Admin → Website | Off by default |
| Careers | Admin → Website, then Careers | Entire section and form are off by default |
| Franchise | Admin → Website, then Franchise | Entire section, form and disclosure are off by default |
| News | Admin → Website, then News | Entire section is off by default |
| Website privacy/data-rights pages | Admin → Website | Editable public information pages |
| Form privacy notices and policy links | Admin → Advanced → Company Settings → Launch Facts | Each enabled form stays closed until its current notice is published |

## Minimum useful opening content

Enter these before customer launch:

- one real store with address, postcode, opening hours and status;
- the opening menu with current prices and availability;
- a monitored public or customer-care email route;
- current Contact form privacy notice and policy link;
- the real owner account with MFA;
- the real allergen notice and staff procedure.

Legal name, company number, social profiles, Careers, Franchise and News can remain blank or disabled until confirmed.

## Publication rule

The public website editor changes website content only. It does not replace the catalogue. All catalogue work goes through **Admin → Menu**, preserving hidden and unavailable products.
