# T13.3.14 — Deployment Polish

**Release identity:** `r4.10.7-t13.3.14-deployment-polish`  
**Application version:** `4.10.7`  
**Date:** 3 August 2026

## Scope

This is a bounded deployment-readiness increment for the existing small-business platform. It does not add a database migration, change roles or permissions, alter RPC contracts, or redesign customer/staff/owner workflows.

## Changes

- Production Netlify deploys now invoke `npm run build:production`, while preview contexts retain the normal advisory build.
- Hashed Vite assets remain immutable without a conflicting catch-all cache directive; the live release marker is explicitly `no-store`.
- The homepage mascot is preloaded from HTML and retains eager/high-priority loading plus intrinsic dimensions.
- Secondary branded images carry intrinsic dimensions, lazy loading where appropriate and asynchronous decoding to reduce layout movement and main-thread contention.
- The production-artifact gate now rejects source maps, missing host files, unresolved entry references and unhashed JavaScript/CSS assets.
- The same gate enforces generous deployment safety budgets for initial JavaScript, total JavaScript, individual chunks and CSS output.
- A dedicated deployment-polish source contract is part of both `npm run verify` and the launch-blocking P0 source suite.
- Current commissioning, environment inventory, release identity and operator links are aligned to T13.3.14.

## Unchanged production boundary

- Ordered upgrade migrations: **104**
- Fresh-install SQL entries: **106**
- Deployable Edge Functions: **17**
- Native/offline iPad till: not part of this web archive
- Production `dist/`: must be created once by the protected release workflow from this exact source

## Release meaning

This source may proceed into the controlled production build and commissioning pipeline after its source gates pass. It is not itself a Netlify upload and does not replace the required locked install, compiled build, PostgreSQL, Playwright, live Supabase, provider and deployment-marker gates.
