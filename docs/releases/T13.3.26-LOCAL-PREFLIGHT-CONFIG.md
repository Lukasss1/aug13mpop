# T13.3.26 — Local preflight configuration

This handoff-only increment changes no application, database, permission or Edge Function business logic.

It makes `npm run public:preflight` usable without copying CI-only data to a developer machine:

- `.env.production.local` is loaded from one committed non-secret template;
- source identity, domain, project ref, Supabase URL and canonical URL are derived;
- release number, commit hash and private-key verification stay in protected CI;
- a private signing key supplied through local dotenv or the shell is refused;
- placeholder public Supabase keys are rejected;
- full CI preflight remains strict and unchanged in authority.
