# T13.3.20 — Final Whole-Tree Audit

**Release identity:** `r4.10.8-t13.3.20-final-audit`  
**Application version:** `4.10.8`  
**Date:** 4 August 2026

This bounded release is the final independent source audit after T13.3.19. It keeps the public website, Admin Panel, Staff Portal and Web Till architecture stable and changes only practical reliability, truthfulness and release-reproducibility issues.

Implemented:

- one append-only database migration that makes concurrent staff-document finalisation idempotent;
- one database invariant that prevents an ended employee from being re-enabled unless a deliberate re-hire clears `ended_at`;
- one shared bounded internal Edge transport for Supabase and Storage calls;
- checked cleanup-job acceptance and explicit reconciliation outcomes instead of unconfirmed success messages;
- database read-back before media cleanup, so an ambiguous registration response cannot delete a successfully registered image;
- returned-row confirmation for staff-document recovery, so a zero-row PostgREST success cannot be mistaken for restored state;
- audited CV signed access and checked worker-result persistence;
- safe segment-by-segment Storage object-path encoding;
- trusted client-IP forwarding to Turnstile;
- a repaired launch-scope verification lane;
- canonical source-file counting shared by embedded and detached release manifests;
- a focused **23/23** final-audit source contract covering only observable small-business safeguards.

Deliberately unchanged:

- customer navigation and page structure;
- staff and manager workflows;
- Web Till payment and recovery architecture;
- role model, store model and business configuration flow;
- large React component boundaries where splitting would add release risk without helping a one- or two-store operator.

This source candidate still requires PostgreSQL execution, a clean locked application build, browser/accessibility tests, live Supabase/Netlify commissioning, a signed frozen build and the human walkthrough under `../archive/commissioning/PRODUCTION-COMMISSIONING-T13.3.20.md`.
