# T13.3.22 — Public Website Scope

**Release identity:** `r4.10.10-t13.3.22-public-web`  
**Database change:** one append-only public-store projection migration  
**Application scope change:** POS routes and navigation deferred

This bounded release prepares the website for a public launch without treating the still-developing POS as an opening dependency.

- A genuine store is publicly listable by real name, address and postcode, including `coming_soon`, without requiring POS/VAT/payment commissioning.
- `setup_status` remains private and still protects trading operations.
- Staff POS navigation and the `/staff/pos` route are removed.
- Web Till Orders and Native Till Ledger are `post_launch` Admin features.
- Historical POS source and database migrations are preserved for later integration.
- The stale fixed migration-count assertion in `test:t133` now binds to the current release manifest.

No broad component rewrite or new state framework was introduced.
