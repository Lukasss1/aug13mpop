- documented Netlify file-digest draft deployment rather than JSON/base64 ZIP transport;
- exact first-release marker 404 before SPA fallback;
- deployment from `dist/` extracted from the verified signed package;
- complete protected-release input preflight before mutation;
- exact Supabase project binding for Direct/Session-Pooler database URLs;
- stronger `fresh` emptiness proof covering public application objects, Auth and Storage;
- atomic fresh schema + seed + empty migration ledger;

- no direct SEO/hosting build hook: static SEO refresh is pending until the next protected release;
