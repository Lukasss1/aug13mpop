# T13.3.16 — Provider Resilience and Modal Accessibility

**Release identity:** `r4.10.7-t13.3.16-provider-resilience`  
**Date:** 3 August 2026

## Scope

This is a bounded source-only reliability and accessibility increment over T13.3.15. It does not change the database chain, RLS, roles, RPC contracts, financial rules, publication rules or intended workflows.

## Changes

- Added one shared Edge Function provider transport with explicit 8-second Turnstile and 15-second e-mail deadlines.
- Kept each provider deadline active through response-body consumption, not only until response headers arrive.
- Applied the bounded transport to anonymous public-form Turnstile verification, CV-upload Turnstile verification, direct staff e-mail and scheduled outbox delivery.
- Made Turnstile provider timeout a distinct temporary-unavailability outcome rather than an indefinitely pending request.
- Added `Idempotency-Key: milkpop-outbox-<job-id>` to scheduled Resend calls so a lost response followed by a retry cannot create a duplicate message for the same outbox row.
- Kept direct-send ambiguity honest: timeout or transport loss is recorded as delivery unconfirmed, and the operator is told to inspect the e-mail log before retrying.
- Converted the entity editor, Store Setup and VAT classification overlays into labelled modal dialogs with deterministic focus, labelled close controls and Escape handling that respects synchronous busy locks.
- Added a 45-check T13.3.16 source contract and included it in both complete verification and the source-only P0 gate.
