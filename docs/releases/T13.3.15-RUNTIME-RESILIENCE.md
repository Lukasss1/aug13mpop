# T13.3.15 — Runtime Resilience

**Release identity:** `r4.10.7-t13.3.15-runtime-resilience`  
**Date:** 3 August 2026

## Scope

This is a bounded source-only reliability and recovery-UX increment over T13.3.14. It does not change the database chain, RLS, roles, RPC contracts, financial rules, publication rules or intended workflows.

## Changes

- Added one shared AbortController-based request deadline helper with conservative classes for authentication, reads, mutations, POS/till operations and uploads.
- Kept each deadline active through response-body consumption, not only until HTTP headers arrive.
- Applied bounded transport to the real browser paths for sign-in/MFA, password recovery, public forms, public fallback loading, authenticated registries, launch settings, staff invites/documents, media, activity logs, SEO rebuild/status, POS reads/RPCs and till payment reads/actions.
- Retained the existing dedicated deadlines in raw logout, refresh and generic PostgREST transports, and kept refresh/public REST deadlines active through the response work they consume.
- Converted image upload transport/timeouts into a typed retryable result and added a component-level processing failure fallback, so the busy state always clears.
- Corrected write-failure copy across staff records, documents, checklists, payroll-facing clocking and SEO rebuilds: transport failure is **unconfirmed**, with reload-before-retry guidance, rather than an unsafe claim that nothing changed.
- Replaced the mouse-only inline image overlay with a disabled-aware, labelled, keyboard-focusable button.
- Corrected crash-recovery wording so the site never promises unsaved information survived.
- Made restricted-admin guidance reflect whether authentication is actually configured.
- Made toast placement safe on narrow screens and capped/deduplicated simultaneous messages.
- Corrected `authClient.ts` documentation so it no longer claims all domain transports route through a currently opt-in primitive.
- Added a runtime-resilience source contract and an executable timeout behavioural unit.
