# T13.3.12 — Deployment Handoff Final

**Release identity:** `r4.10.6-t13.3.12-deployment-handoff-final`  
**Application version:** `4.10.6`

## Purpose

This release is the final source handoff for protected production deployment. It adds no business module and no redesign. It closes four narrow deployment-quality gaps found during the last adversarial review.

## Final corrections

- Anonymous public-form bodies are limited to 32 KiB before JSON parsing, require JSON content type, and accept only a plain object containing bounded strings.
- Privacy evidence is validated as a bounded notice identifier plus an exact SHA-256 value before the database gate.
- Contact and franchise inboxes use explicit least-data projections; idempotency, request-hash and privacy-evidence metadata no longer travel to the browser during normal inbox reads.
- Public Supabase reads have a 12-second abort boundary and all independent public collections hydrate concurrently, preventing one failing relation from multiplying startup delay.
- Fresh-install and seed defaults no longer infer `MILK POP` as a registered legal entity.
- The canonical website default is the real HTTPS root `https://milkpop.uk`, while the footer displays the clean host.
- Replaying the production seed no longer mutates the site-settings timestamp.
