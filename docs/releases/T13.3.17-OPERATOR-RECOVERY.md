# T13.3.17 — Operator Recovery and Browser Reliability

**Release identity:** `r4.10.7-t13.3.17-operator-recovery`  
**Application version:** `4.10.7`  
**Date:** 3 August 2026

This bounded source-only increment preserves T13.3.16 and closes browser behaviours that could make a valid operator action look broken even when the backend was healthy.

## Changes

- Public boot/focus/identity refreshes now share one in-flight cloud pull, preventing an older overlapping response from finishing last and overwriting fresher public configuration.
- A visible tab retries public and authenticated hydration immediately when the browser reports that connectivity has returned.
- Owner document and candidate-CV actions reserve a blank tab synchronously from the click, sever `window.opener`, close it on refusal, and navigate it only after the signed URL passes the existing safe-URL boundary. When a tab cannot be reserved, the same verified link opens in the current tab.
- The legacy held-sale JSON action now reports copy success only after the Clipboard API confirms it; rejected or unavailable clipboard access produces a warning.
- Password reset and password completion are native forms with browser validation, password-manager metadata, duplicate-submit guards, correct live-region roles, and timer cleanup on unmount.
- Staff document label/category controls now have programmatic labels and native required validation.
- The customer-mail fallback launches `mailto:` without depending on a pop-up.
- A 27-check T13.3.17 source contract is included in complete verification and the source-only P0 gate.

## Scope

No database migration, RLS policy, permission, role, RPC, payment, payroll, VAT, e-mail provider or intended business-workflow change was made. The chain remains **104 upgrade migrations / 106 fresh-install SQL entries**, with **17** deployable Edge Functions.

Production `GO` still requires the locked dependency install, official typecheck/lint/build, browser suites, PostgreSQL suites and real Supabase/Netlify commissioning in `../archive/commissioning/PRODUCTION-COMMISSIONING-T13.3.18.md`.
